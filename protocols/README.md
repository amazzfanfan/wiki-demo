# protocols/ — 维基协议层

这是 LLM Wiki 的灵魂层。定义了"知识库应该怎么被维护"，Agent 每次执行写入前必须预读。

## 文件说明

| 文件 | 作用 | 每次必读？ |
|------|------|-----------|
| `purpose.md` | 定义知识库使命边界、核心论点、三大元规则 | ✅ 每次摄入必读 |
| `schema.md` | 定义操作 SOP：双链语法、页面模板、降级策略、禁止操作 | ✅ 每次写入必读 |

## purpose.md — 知识库的灵魂

三个核心元规则：

1. **双链优先于标签**：`[[page]]` 优先于 `#tag`
2. **写入即承诺**：禁止留下悬空引用（死链）
3. **先分析再写，写完即同步**：分析师只读不做写，撰稿人只写不分析

## schema.md — 操作规范 SOP

- **页面命名**：kebab-case
- **双链语法**：`[[target]]` / `<!-- backlink:source -->`
- **页面模板**：Abstract → Key Concepts → Details → Related → References
- **降级策略**：死链 → 自动建最小模板；循环引用 → 追加警告
- **禁止操作**：禁止修改时间戳、禁止删除、禁止超范围写

## 扩展指引

- **新增协议**：在本目录新建 `.md` 文件，Agent instructions 中可通过文件读取引用
- **修改规范**：直接编辑 `schema.md`，Agent 下次摄入/写入时自动生效
- **不在此目录放 Python 代码**：这里是纯 Markdown 协议层
