# LLM Wiki 模型工厂配置方案

> 最后更新：2026-07-10
> 入口文件：`core/llm_factory.py`

## 设计原则

1. **一个入口**：所有 LLM 调用统一走 `get_qwen_model(model_id=None, role=None)`
2. **用户无感**：系统预置的模型写 `.env`，用户不需要知道后端用的什么
3. **BYOK 优先**：用户自己在前端设置页配的 API Key 永远优先于系统默认
4. **一行切换**：改 `DEFAULT_PROVIDER` 即可切换全局提供商，不需要改代码
5. **角色可独立覆盖**：每个角色可通过 `{ROLE}_MODEL_ID` 单独指定模型

## 优先级链

```
① 用户 BYOK（前端设置页 → users.db.api_keys）
   ↓ 用户没配
② 角色覆盖（.env 中的 {ROLE}_MODEL_ID）
   ↓ 角色没设
③ DEFAULT_PROVIDER 指定的提供商（.env 一行切换）
   ↓ 没设或写错
④ 自动选第一个有 API Key 的提供商（兜底）
   ↓ 全没有
⑤ 报错提示用户去设置页配 Key
```

## 提供商配置

通过 `_PROVIDERS` dict 注册，三家内置：

| 名称 | API Key 环境变量 | Base URL 环境变量 | URL 默认值 | Model ID 环境变量 |
|------|-----------------|------------------|-----------|------------------|
| `qwen` | `QWEN_API_KEY` | `QWEN_BASE_URL` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `QWEN_MODEL_ID` |
| `dsv4pro` | `DSV4PRO_API_KEY` | `DSV4PRO_BASE_URL` | `http://your-internal-llm-service:30000/v1` | `DSV4PRO_MODEL_ID` |
| `glm` | `GLM_API_KEY` | `GLM_BASE_URL` | `http://your-internal-llm-service:30000/v1` | `GLM_MODEL_ID` |

### 新增提供商

在 `core/llm_factory.py` 的 `_PROVIDERS` dict 里加一项：

```python
"openai": {
    "key_env": "OPENAI_API_KEY",
    "url_env": "OPENAI_BASE_URL",
    "url_default": "https://api.openai.com/v1",
    "model_env": "OPENAI_MODEL_ID",
    "model_default": "gpt-4o",
},
```

不需要改任何其他代码，所有角色自动可用。

## 角色配置

7 个角色，每个可通过环境变量单独覆盖 model_id：

| role | 覆盖环境变量 | 用途 | 调用文件 |
|------|-------------|------|---------|
| `map` | `MAP_MODEL_ID` | MAP 阶段概念提取（高并发） | `agents/wiki_analyst.py` |
| `editor` | `EDITOR_MODEL_ID` | REDUCE 阶段知识融合 | `agents/wiki_editor.py` |
| `schema` | `SCHEMA_MODEL_ID` | Schema Phase 0 领域嗅探 | `workflows/ingest_flow.py` |
| `schema_suggest` | `SCHEMA_SUGGEST_MODEL_ID` | Schema 演化建议 | `workflows/ingest_flow.py` |
| `query` | `QUERY_MODEL_ID` | 查询路由 + 回答生成 | `agents/wiki_query.py` |
| `research` | `RESEARCH_MODEL_ID` | 网络研究（带工具调用） | `agents/web_researcher.py` |
| *(default)* | `QWEN_MODEL_ID` | IntentRouter / local_wiki 等 | `app.py`, `agents/local_wiki.py` |

## 使用场景速查

| 想做的事 | 怎么配（改 .env） |
|---------|-----------------|
| 全切 DashScope | `DEFAULT_PROVIDER=qwen` |
| 全切私有化部署 DeepSeek | `DEFAULT_PROVIDER=dsv4pro` |
| 全切私有化部署 GLM | `DEFAULT_PROVIDER=glm` |
| DashScope + REDUCE 用 GPT-4o | `DEFAULT_PROVIDER=qwen` + `EDITOR_MODEL_ID=gpt-4o` |
| 啥都不配 | 自动选第一个有 key 的（兜底） |

## 当前配置（2026-07-10）

```env
# 全局提供商
DEFAULT_PROVIDER=qwen

# DashScope（用户个人 key，速度快 ~11s）
QWEN_API_KEY=sk-xxx
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_MODEL_ID=deepseek-v4-pro

# 私有化部署 DeepSeek（示例配置）
DSV4PRO_API_KEY=sk-xxx
DSV4PRO_BASE_URL=http://your-internal-llm-service:30000/v1
DSV4PRO_MODEL_ID=/your/model/path

# 私有化部署 GLM（示例配置）
GLM_API_KEY=sk-xxx
GLM_BASE_URL=http://your-internal-llm-service:30000/v1
GLM_MODEL_ID=/your/model/path
```

## 已知约束

- **GLM 5.2 tool calling 不兼容 agno**：sglang 部署的 GLM 5.2 不支持 `output_schema` 结构化输出，Editor 用它会返回空。当前 GLM 仅做备用。
- **公司 DSV4Pro 压力测试期间慢**：Phase 0 实测 ~290s，当前切 DashScope（~11s）。压力测试结束后可切回 `DEFAULT_PROVIDER=dsv4pro`。
- **BYOK 用户上下文不跨线程**：后台线程（如 ingest 的 Schema Phase 0）通过 `threading.local()` 获取用户上下文，中间件在入口设置。如果后台线程没有继承，会回退到系统默认。
